Druva App for Microsoft Sentinel

An Interactive Installation & Configuration Guide

Overview

This guide provides a comprehensive, step-by-step walkthrough for integrating the Druva Data Security Cloud with Microsoft Sentinel. By connecting Druva to Sentinel, you can stream critical security and operational events, enabling unified threat detection, proactive monitoring, and streamlined incident response within a single platform.

Key Features

  • ➔ Unified visibility into backup and security events.
  • ➔ Real-time alerts for suspicious activities and data anomalies.
  • ➔ Automated response workflows with pre-built playbooks.
  • ➔ Bidirectional sync to quarantine snapshots from Sentinel.

Benefits

  • ✓ Enhance threat detection with backup telemetry.
  • ✓ Accelerate incident response and recovery.
  • ✓ Improve security posture and compliance reporting.
  • ✓ Centralize security operations for IT and SecOps teams.

Prerequisites Checklist

  • Active Azure Subscription with necessary permissions.
  • A Log Analytics workspace with Microsoft Sentinel enabled.
  • Contributor permissions on the Azure subscription.
  • Microsoft Sentinel Contributor permissions on the resource group.
  • Druva API Client ID and Client Secret generated.
  • Appropriate Druva license (e.g., Accelerated Ransomware Recovery).

Installation & Configuration Steps

Phase 0: Azure Environment Setup

1

Create a Dedicated Resource Group

Organize all your Sentinel resources in one place for easier management.

  1. In the Azure portal, search for and select Resource groups.
  2. Click + Create.
  3. Enter a name (e.g., `DruvaSentinel-RG`), select your subscription, and choose a region.
  4. Click Review + create and then Create.
2

Create a Log Analytics Workspace

This workspace will house all your security event data.

  1. In the Azure portal, search for and select Log Analytics workspaces.
  2. Click + Create.
  3. Select the resource group you just created.
  4. Enter a name for the workspace (e.g., `DruvaSentinel-Workspace`), and click Review + create.
  5. Click Create.

Phase 1: Deploy Druva App from Azure Marketplace

3

Find the App in Azure Marketplace

Access the Marketplace and search for the Druva integration.

Sign in to the Azure portal, navigate to the Marketplace, and search for "Druva Integration with Microsoft Sentinel".

4

Initiate Deployment

Start the installation process by adding the app to your tenant.

Click on the app and select "Get it now" to begin the deployment wizard.

5

Configure Project Details

Assign the app to your specific Sentinel workspace.

  • Select your Azure Subscription.
  • Choose the correct Resource Group.
  • Select the target Sentinel-enabled Workspace Name.
  • Follow the prompts to review and complete the deployment.

Phase 2: Configure the Data Connector

6

Navigate to Data Connectors

Find the newly installed Druva connector in Sentinel.

In your Sentinel workspace, go to Configuration > Data Connectors and search for "Druva Events Connector".

7

Provide Druva API Credentials

Enter your Druva API details to authorize the connection.

On the connector page, input the following:

  • Hostname: `apis.druva.com` (for Public Cloud)
  • Client ID: Your Druva API Client ID.
  • Client Secret: Your Druva API Client Secret.
8

Verify Connection & Data Flow

Confirm that Druva events are being ingested into Sentinel.

After clicking "Connect", check the status on the connector page. Then, navigate to the Logs section and run a KQL query to see the data:

DruvaSecurityEvents_CL | take 10

Phase 3: Advanced Configurations

9

Configure Playbooks

Set up automated response workflows to act on threats.

The Druva solution includes pre-built playbooks to automate responses. To use them:

  1. In Sentinel, navigate to Automation > Playbooks.
  2. Find the Druva-related playbooks (e.g., for quarantining snapshots).
  3. Click on a playbook to view its details and deploy it.
  4. Configure any required connections or parameters for the playbook to function.
10

Enable Copilot for Security Plugin

Integrate with AI to enhance threat detection and analysis.

Druva offers a plugin for Microsoft Copilot for Security, which uses AI to provide deeper insights. To enable it:

  1. In your Copilot for Security account, go to the Non-Microsoft plugin section.
  2. Find the Druva Sentinel Plugin and click Setup.
  3. Provide your Sentinel environment details: Tenant ID, Subscription ID, Workspace Name, and Resource Group Name.
  4. Click Save to verify and enable the plugin.
