Druva to Splunk Integration for SIEM Capabilities

This guide outlines the process of integrating the Druva Cloud Platform with Splunk, a leading Security Information and Event Management (SIEM) solution. By forwarding security-related events from Druva to Splunk, you can centralize your log data and correlate backup and restore activities with other security events across your environment.

The Integration Process

Step 1: Install the Druva Add-on for Splunk

The easiest way to integrate Druva is by using the official add-on from Splunkbase.

  • Log in to your Splunk Web console.
  • In the Splunk Enterprise app bar, click **Apps > Manage Apps**.
  • Click **Browse more apps** and search for "Druva".
  • Click **Install** on the **Druva Add-on for Splunk** page. You may need to restart Splunk after installation.

Step 2: Generate API Credentials in the Druva Console

You'll need to create dedicated API credentials in your Druva console to allow Splunk to securely connect and retrieve event data.

  • Log in to your Druva Cloud Platform console.
  • Navigate to **Integration Center** from the main menu.
  • Click on **Add API Client** and provide a descriptive name, such as "Splunk-Integration".
  • Grant the client **read-only access** to event and security logs. Avoid granting any other permissions.
  • After creation, you will be provided with a **Client ID** and a **Client Secret**. Copy these values, as they are shown only once.

Step 3: Configure the Druva Add-on in Splunk

Now you'll configure the add-on in Splunk with the credentials from Druva.

  • In your Splunk console, go to **Apps** and find the **Druva Add-on for Splunk**.
  • Navigate to the **Configuration** or **Inputs** tab.
  • Click **Add New Input** and enter a descriptive name.
  • Paste the **Client ID** and **Client Secret** you copied from the Druva console.
  • (Optional) Configure the **Interval** to set how often Splunk should check for new data. The default is usually every 15 minutes.
  • Save the configuration. The add-on will now begin pulling event data from Druva.

Step 4: Verify Data and Build Dashboards

Once the add-on is configured, you can verify that data is flowing into Splunk and begin using it for monitoring and analysis.

  • In Splunk, go to the **Search & Reporting** app and run a search for `sourcetype="druva:events"`.
  • You should see logs from your Druva environment. The add-on automatically parses the data into a usable format.
  • From here, you can create custom dashboards, build alerts, and run reports on your Druva security events.

This streamlined process, using the official add-on, provides a robust and centralized view of your data protection security posture, enabling you to correlate these events with other security data in your Splunk environment.
